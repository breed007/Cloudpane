# Keyboard shortcuts

| Keys | What it does |
| --- | --- |
| ⌘R | Scan now |
| ⌘. | Stop the scan |
| ⌘0 | Show the Cloudpane window |
| ⌘? | Open Cloudpane Help |
| ⌘W | Close the window. Closing the main window quits Cloudpane unless Help is open. |
| ⌘Q | Quit Cloudpane |

Scan now and Stop scan are also in the Scan menu.
