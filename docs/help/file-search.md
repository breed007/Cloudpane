# File search

Type part of a file name to search every provider in the latest scan at once. Case does not matter, so "resume" finds "Resume.pdf". Accents do: "resume" does not find "résumé.pdf".

Each result shows the provider, the path, the size, when it was modified, and where the data is: on this Mac or only in the cloud. The list shows up to 1,000 matches.

<!-- macOS -->
Reveal in Finder and Copy path are the only actions on a file, from the bar at the bottom of the view or by right-clicking a result. Cloudpane never opens, moves or changes a file.
<!-- /macOS -->

The same name in two providers usually means a copy. [Duplicates](duplicates.md) finds those for you.
